Bugtracker has been moved from RootNode to OVH server last night and since then there is only one valid URL: [http://bugs.openmw.org](http://bugs.openmw.org "http://bugs.openmw.org"). Please don’t use [http://bugs.openmw.org:81/](http://bugs.openmw.org "http://bugs.openmw.org") (URL with :81, port number, suffix), it won’t work any more.
